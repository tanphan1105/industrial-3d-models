TYPE 01 / CONSTELLATION

IoT Neural Network

Mạng lưới các điểm cảm biến phân tán. Khi rê chuột, các đường liên kết sẽ tự động dò tìm và kết nối tới con trỏ chuột, mô phỏng mạng viễn thông thu thập dữ liệu SCADA.

TYPE 02 / DATA STREAM

Telemetry Stream

Luồng dữ liệu nhị phân/hexadecimal rơi tự do (Digital Rain). Biểu diễn hàng triệu bản ghi thông số kỹ thuật (Áp suất, Lưu lượng, TDS) đang được đẩy lên Server liên tục.

TYPE 03 / HEX MEMBRANE

RO Membrane Grid

Cấu trúc tổ ong mô phỏng bề mặt màng lọc RO (Reverse Osmosis). Rê chuột để kích hoạt các lỗ màng lọc, ánh sáng sẽ chạy lan tỏa qua các node xung quanh.

TYPE 04 / CIRCUIT BOARD

Logic Circuit Flow

Các luồng điện (Data pulse) chạy dọc theo ma trận vuông góc. Ứng dụng để minh họa bo mạch PLC S7-1200 hoặc luồng tín hiệu tự động hóa 24/7 trong tủ điện.
